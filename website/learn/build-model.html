SPARK_BC factory

Beyond HTTP train jobs: Spark compiles Spark to SPARK_BC (orchestration ISA, not neural weights) with TRAIN 0x26 / STEP 0x28 / TRAIN_STATUS 0x27, then emits Spark-created init safetensors. Dry fixture ≠ SGD ≠ trained. GAS does not emit .sparkbc. Full reproduce commands + sha256 table: Builder — SPARK_BC factory.
