# spark-model-lab

Companion for `model reverse` / `inspect`. Installed as
`./spark-model-lab` from `spark_model_lab.sh`.

```bash
./spark-model-lab --dry reverse
./spark-model-lab --live reverse --model examples/fixtures/models/tiny-lm
```

Language pipeline (GAS `./spark`): `examples/model_lab.spark`.
See `docs/MODEL_LAB.md`.
