Welcome to Spark

Spark is an AI-first language runtime: one reviewable .spark file per workflow — ask, classify, extract, pipeline, review, model analyze, and voice.

This installer will:

  • Place the Spark runtime under /usr/local/spark
  • Compile bootstrap + sparkasm on first install (build.sh)
  • Include nine AI example programs and a quick-start guide

Dry-run offline with fixtures; go live with any OpenAI-compatible API and OPENAI_API_KEY.
