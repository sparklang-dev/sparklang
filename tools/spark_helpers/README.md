# SparkLang helpers (I-lane / pack)

Thin wrappers around real compile / decompile / inspect paths.

| Script | What |
|--------|------|
| `compile.sh` | `spark-bootstrap --compile` |
| `decompile.sh` | `bc_dump` / GUI core decompile |
| `opcode_sheet.py` | Opcode table from `bc_dump.OP_NAME` |
| `fixture_lint.py` | JSONL train fixture shape check |

CPU only. Never 6000. Does not claim beat Claude.
