# Decompile capabilities — measured

What Spark's decompile toolchain does today, measured on real
artifacts and rerunnable from the repo. Spark / SparkLang only.

Related: [Decompile](DECOMPILE.md) ·
[SPARK_BC.md](SPARK_BC.md) ·
site [/docs/decompile-capabilities.html](/docs/decompile-capabilities.html).

## Measured capabilities (SPARK_BC domain)

| Capability | Evidence |
|------------|----------|
| **100% round-trip** | `compile → dump → recompile` the same `.spark` → identical sha256 on the published fixtures (`tools/spark-bc-dump/roundtrip.py`) |
| **Structured dump** | Sections + string symbols + const/op xrefs + txt/JSON/HTML export (`bc_dump.analyze_bc`) |
| **Local privacy** | No upload — the analysis project stays on disk |
| **Integrated train / weights** | The same bytecode drives TRAIN/STEP + init safetensors |

Multi-format ELF/PE interactive decompile is a different domain.
Spark's local probe indexes ELF headers and sections on real
binaries; it does not pretend to be a full native decompiler, and
the scoreboard marks that row as a measured **loss** against the
broader domain.

## Measured probes

Two standalone probes publish their raw results under
`website/data/probes/`:

- **Multi-format PE probe** (`make probe-pe` →
  [pe_multiformat.json](/data/probes/pe_multiformat.json)) —
  `spark-binary-probe --pe` parses real PE32/PE32+ fixtures:
  format detection, entry VA, section table, and import DLLs,
  each cross-checked against the system binutils reference, with
  pinned sha256 per fixture and loud-fail negative cases.
- **LLM-assist probe** (`make probe-assist` →
  [llm_assist_decompile.json](/data/probes/llm_assist_decompile.json)) —
  the grounded assist lane consumes dump text only: offline
  grounding passes on the published fixtures, distinct inputs
  produce distinct outputs, and prompt-injection text in a dump is
  rejected. Assist suggests comments and names; it never rewrites
  `.sparkbc`. Policy: `docs/DECOMPILE_ASSIST_POLICY.md` in the
  repo.

## Commands

```bash
make spark-bootstrap spark
make test-decompile-compete # unit: richer dump + project
make decompile-roundtrip # compile→dump→recompile hash
make decompile-bench # metrics + scoreboard JSON
# also records elf_local_probe from ./spark-binary-probe --elf
./spark-binary-probe --elf ./spark
```

Analysis project (single file):

```bash
PYTHONPATH=python python3 tools/spark-bc-dump/analyze_project.py \
 docs/examples/spark-train-step.sparkbc \
 -o out/analyze/train-step \
 --source examples/spark_train_step.spark
```

Richer dump exports:

```bash
PYTHONPATH=python python3 tools/spark-bc-dump/dump.py \
 docs/examples/spark-train-step.sparkbc --json -o /tmp/bc.json
PYTHONPATH=python python3 tools/spark-bc-dump/dump.py \
 docs/examples/spark-train-step.sparkbc --html -o /tmp/bc.html
```
